# Firefly 国内三网免费拨测基线（2026-10-10）

> **实验基线，不是生产 SLA。** 仅使用 17CE 正常免费网页检测，不调用收费 API、不绕验证码、不使用 TinyFish。所有检测目标均为项目公开 URL；生产 DNS、Worker、原图没有修改。

## 固定约束

- `casto.top` 不备案，不购服务器，不开通会产生额外费用的服务。
- 原图保留完整字节，不在上传时压缩或转码；缩略图另行生成。
- 优先验证大陆电信、联通、移动的实际 HTTPS 成功率与下载速度；海外测点不能冒充国内数据。
- 生产 `blog.casto.top` / `img.casto.top` 未通过多时段验收前不切换线路，必须保留可回退的旧访问路径。

## 技术选择及下一阶段（需实验验证）

1. **不切生产。** CF 相较现有图床改善 HTTP 响应，但全国的完整下载成功率仍未达到验收标准。
2. **先做静态缩略图分发：** 将演示版内嵌 Worker 的预生成 WebP 迁为真正的 Workers Static Assets（不额外消耗动态 Worker 的每日免费请求配额）；每版本不超过官方免费文件数量上限，并规划前缀分片。只生成衍生缩略图，原图 SHA-256 不变。
3. **建立第二条免费海外 CDN 对照：** 优先评估无需备案的 ESA 全球不含中国大陆加速（必须先确认阿里云账户与免费套餐资格；无授权不创建套餐）；或评估已有免费部署服务的独立静态预览。与 CF 用同一图片字节、相同缓存热度、相同三网测点重复测试，不开通任何付费资源。
4. **按地区/运营商验收：** 每个平台至少 3 个时段、各运营商多个地区，分开统计 DNS/连接失败、HTTP 200、**完整响应体**、P50/P75/P95。17CE 对大原图的免费检测不能证明完整下载，要与真实浏览器补充。
5. **博客站点独立优化：** EdgeOne 网页本身也有跨境失败与较慢节点，需要单独比对 HTML 首字节、CSS/JS 加载与 LCP；在实验域名做好回退后再考虑 DNS。
6. **容量和灾备**：图床当前是 TelegramNew 原图 + KV 索引，严格分开上传原图、生成缩略图和异地可恢复 SHA-256 备份。公开报告不得包含 KV 内 Telegram token 等敏感字段。
7. **正式切换门槛**：零新付费，国内三网长时间成功率目标 99% 或更高、缩略图热缓存 P75 目标 <1 秒；无法达标就保留现有生产，不伪称完成。

## 安全和平台使用

没有绕过 ITDOG 或 BOCE 的验证码/403；17CE 使用人机可见的免费网页控件提交受控测试，没有访问收费 API。没有自动启动新服务器、启用账单、操作 DNS 或修改原图。全国检测报告由独立第三方节点生成，节点临时故障和报告分享链接可能失效，原始报告与项目快照应同时保存。
