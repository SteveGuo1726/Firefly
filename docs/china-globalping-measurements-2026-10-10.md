# Firefly 不备案免费三网拨测 · 2026-10-10

## 方案说明

使用 **Globalping 公共 API**（https://api.globalping.io/v1）。
匿名无需 API Key：每小时 250 个测试、单次最多 50 个探针。获取在线探针列表不限次数。
只测试公开域名和一张固定公开测试图片。脚本：`node scripts/china-three-isp-probe.mjs`。

本次读取到约 **5200 在线探针，其中 47 个大陆 CN 探针**：
中国移动主网 AS9808：4 个；中国联通 AS4837：7 个；中国电信 AS4134：4 个。
其它大陆探针属于腾讯/阿里/华为云机房、其他网络；不应混称为普通居民网络。

首次从以上三网各选 2 个探针，再以 Globalping Measurement ID 复用**同一批**测量节点，分别执行 4 个公开 HTTPS GET。
请求超时阈值 15 秒，失败即使拿到 HTTP 200 也算失败。
这些测试是**大陆节点到公网 URL 的 HTTP 请求**，不是移动端浏览器渲染 LCP，也不是全国三网覆盖保证。

## 结论与下一次实验

1. 当前 EdgeOne 博客页面**不宜迁移**，因为 6/6 大陆公开探针均可返回 HTTP 200。
2. 静态 WebP 缩略图在真实珠海设备中效果明显，因此应尽快在实验画廊网格中默认加载缩略图、点击后才读原图。
3. 当前 Cloudflare 免费 Anycast 图像线路在大陆探针仅 3/6 或 4/6 成功，**未达到正式切换要求**。即便文件很小也会出现 15 秒超时。
4. 同一批探针还需比较第二个免费海外 CDN 试验入口（例如 ESA 全球不含大陆免费版，如果以后获得受控账号访问），不能拿境外 VPS 的测速假冒三网结果。
5. 试验版现在的 WebP 是固定样本，嵌在 Worker 中，仍按动态 Worker 请求限额计量。正式规模化应改成独立静态缩略图库，并保留原图 SHA-256 与异地备份。
6. 这次没有开启付费接口：BOCE、17CE 官方 API 都采用按量付费，因此未调用。Globalping 的默认免费限制由脚本硬性控制在 **24 个测试/一次运行**。

零备案、零新服务器、零新增付费、原图字节不变；正式 DNS、博客和 ImageBed 生产服务没有更改。
